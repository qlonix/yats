# YATS 開発ルール

本プロジェクトにおいて遵守すべき開発ルールを以下に定義する。

## 1. バージョン管理
- バージョン番号は `a.b.c`（セマンティックバージョニング形式）の3つの数字で構成する。
- **ユーザーの明示的な指示があるまで、3つ目の数字（Patchバージョン: c）のみを加算していく。**
- メジャーバージョン（a）およびマイナーバージョン（b）の変更は、ユーザーの直接の指示に従う。

## 2. 言語設定
- **基本言語は日本語とする。**
- 以下の項目には日本語を使用すること：
  - アプリケーション内のメッセージ類（UIテキスト、アラート等）
  - ソースコード内のコメント
  - コミットメッセージ
  - ユーザー（Antigravity）との対話および報告書類（artifacts）

## 3. 運用・ワークフロー
- **開発ルールは `.agent/rules.md` に明記し、適宜更新する。**
- **コード類に変更があった場合は、都度 GitHub へプッシュ（git push）を行う。**
- **GitHubのReleasesは指示があるまで追加/変更しない。**
- **GitHubのReleasesのAssetsへの追加・アップデートは指示があるまで行わない。**
- **Windows 版のビルドはローカルだけで行う。GitHub Actions でのビルドは禁止する。**
- **ビルド成果物（Windows, Linux 共に）は、ビルドの都度 `Z:\devel\Antigravity\yats\[バージョン番号]` フォルダにコピーして保管する。**
- **変更履歴を `CHANGELOG.md` に記載していく。**
